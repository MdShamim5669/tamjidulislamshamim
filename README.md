# Premium-Portfoilo-Client ✦

> Modern, luxury animated portfolio web application built with **Next.js 14 (App Router)**, **TypeScript**, **Framer Motion**, **Three.js / Canvas Sequence Shaders**, and **Tailwind / Vanilla CSS**.

---

## ⚡ Highlights & Key Features

- 🏎️ **ThreeUI EV Power Performance Gauge Loader**: Circular dial with polar tick geometry, sweeping needle beam, and battery state-of-charge readout.
- 🎬 **60FPS Canvas Animation Engine**: 240 high-resolution viewport-synchronized frame sequence.
- ⌨️ **Typewriter Text Animation**: Dynamic letter-by-letter typing with pulsing glowing neon cursor across hero and section headers.
- 🎨 **Editorial Layouts**: Panoramic draggable course carousels, split-screen project modals, dynamic timeline indicators, and interactive accordion stacks.
- 💎 **Pure Glassmorphism & Micro-Interactions**: Ambient radial glow, hover magnification, and responsive layouts.
- ⚡ **TanStack React Query Integration**: Real-time hydration with PostgreSQL & Prisma backend.

---

## 🛠️ Tech Stack

- **Framework**: [Next.js 14](https://nextjs.org/) (App Router)
- **Language**: TypeScript
- **Styling**: Vanilla CSS & Tailwind CSS tokens
- **Animations**: Framer Motion & HTML5 Canvas 2D Engine
- **State & Data Hydration**: `@tanstack/react-query`, Axios
- **Icons & UI**: Lucide Icons, Sonner Toasts

---

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Run the development server
npm run dev

# Open http://localhost:3000 in your browser
```
